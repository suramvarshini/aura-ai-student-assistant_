      Model Context Protocol (MCP) Server

      Native MCP server architecture implemented via @modelcontextprotocol/sdk with secure session isolation.

      Architecture & Transport

      Remote Streamable HTTP / SSE

      Exposes standard Model Context Protocol endpoints:

      GET /api/mcp/sse — Server-Sent Events stream for external & in-app MCP clients.
      POST /api/mcp/messages — Bidirectional JSON-RPC messages.
      POST /api/mcp/execute — In-app zero-latency authenticated execution.
      Transport: SSE Active
      Security & Isolation

      Per-User Google Credential Isolation

      👂 Listening for "Hey Aura"
      🎙️ Hands-Free "Hey Aura" Activation

      Enable continuous hands-free voice control so you can speak to Aura anytime without clicking buttons.

      How It Works:

      • Say "Hey Aura" followed by any command (e.g. "Hey Aura, what assignments are due tomorrow?").
      • Aura plays a soft activation chime and speaks the response aloud.
      • After responding, Aura automatically resumes listening for the next wake word.
      🔒 Privacy & Safety Guarantee:

      Audio is never saved, uploaded, or recorded to disk. Processing is handled live in-memory by browser speech capabilities. Consequential actions (such as submitting an assignment) strictly require manual confirmation.

      A visible indicator and instant "Stop Mic" button will remain active whenever the microphone is on.
